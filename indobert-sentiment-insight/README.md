# IndoBERT Sentiment Insight

Aplikasi analisis sentimen Bahasa Indonesia menggunakan model IndoBERT yang telah di-fine-tuning.

Masukkan sebuah kalimat, kemudian sistem akan memprediksi apakah sentimen tersebut **Positive**, **Negative**, atau **Neutral**.
